# 🚗 Car Rental System

A simple **Python-based Car Rental System** that calculates the total rental cost based on car type, rental duration, membership discounts, optional services, and late return penalties.

## ✨ Features

* 🚘 Choose Economy, Standard, or Luxury cars
* 📅 Calculate rental cost based on number of days
* 💳 Apply Premium or Standard membership discounts
* 🛡️ Add optional Insurance and GPS
* ⏰ Calculate late return penalties
* 🧾 Display a complete rental summary
* ✅ Basic input validation and error handling

## 🛠️ Technologies

* Python 3
* Dictionaries
* Functions
* Conditional statements
* Exception handling

## ▶️ How to Run

```bash
python car_rental.py
```

## 💡 Example

```text
Car Type: Luxury
Daily Rate: $100
Rental Days: 5
Membership Discount: -$75.00
Insurance Fee: $100
GPS Fee: $25
Late Penalty: $30
Total Rental Fee: $580.00
```

## 🎯 Purpose

This project was created to practice **Python fundamentals, user input, calculations, dictionaries, validation, and exception handling**.
